Referral Dashboard
📖 Overview
The Referral Dashboard is a modern, responsive web application built with React and Vite. It serves as a centralized platform for users to easily track their referral performance, monitor earnings, and manage partner activity. Designed with user experience in mind, the dashboard provides a clear, high-level summary alongside detailed, interactive data tables.

✨ Key Features
Secure Authentication: JWT-based login system with protected routes to ensure user data remains private and secure.
Interactive Dashboard Overview: A high-level view of key metrics, including total referral earnings, active referrals, and service summaries.
Referral Management Table: A comprehensive, paginated table displaying all referrals (including name, service, date, and profit). Features real-time search filtering and chronological sorting.
Detailed Views: Users can drill down into specific referrals by clicking on table rows to view in-depth information.
Easy Sharing: A quick-access section with built-in controls to copy personal referral links and codes directly to the clipboard.
🛠️ Tech Stack
Frontend Framework: React 19 powered by Vite for lightning-fast builds and hot module replacement (HMR).
Routing: React Router v7 for seamless single-page application (SPA) navigation and route protection.
Styling: Vanilla CSS for a lightweight, highly customizable, and responsive design.
State Management & Data: React Hooks (useState, useEffect, useMemo) combined with RESTful API integration (via AWS API Gateway).
Token Management: js-cookie for secure storage and handling of authentication tokens.
